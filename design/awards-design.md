# 2026년 10월 시상식 디자인 규칙

- 16:9 비율, 13.333 × 7.5인치.
- 배경: 아이보리 F7F4EC. 본문: 차콜 292722. 포인트: 샴페인 골드 A38A55.
- 보조 테두리: D6C7A6 / D7CDBA. 본문과 수상자 이름은 대비가 높은 차콜 사용.
- 좌우 기본 여백: 0.72~0.8인치. 하단 공통 구분선: 6.97인치.
- 한글: Apple SD Gothic Neo. 영문 메인: Baskerville. 영문 보조: Avenir Next.
- 제목 30~65pt, 수상자 이름 23~39pt, 수상 사유 19pt. 상 이름은 골드로 강조.
- 사진 5명 소개는 동일한 크기와 간격으로 배치. 개인 슬라이드는 사진 왼쪽, 수상 정보 오른쪽.
- 장식은 가는 선, 다이아몬드, 사진 뒤의 오프셋 테두리로 제한.
- 모든 글자와 장식은 편집 가능한 텍스트 또는 도형으로 생성.
- 실제 수상자 자료가 없으면 명시적 자리표시자를 사용하고 수상 실적을 임의로 작성하지 않음.
- 내용 변경 후 `npm run build` 및 `npm run preview`로 결과를 확인.
