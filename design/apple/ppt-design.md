# Apple 기반 PPT 기본 디자인

원본: [DESIGN-apple.md](DESIGN-apple.md). 실행용 수치: [theme.json](theme.json).

## 슬라이드로의 해석
- 기본 화면은 16:9. 슬라이드 하나에 핵심 메시지 하나를 둔다.
- 화이트 #FFFFFF, 라이트 그레이 #F5F5F7, 다크 #272729를 내용 흐름에 따라 교차한다. 밝은 슬라이드에 #1D1D1F, 어두운 슬라이드에 흰색을 쓴다.
- 강조는 블루 #0066CC 하나를 사용하고, 다크 배경에서는 #2997FF를 쓴다. 웹 링크·버튼 규칙은 실제 행동이나 핵심 강조가 있을 때만 PPT에 적용한다.
- 제목 36–54pt, 리드 24pt, 본문 18–24pt, 보조 문구 11–14pt. 원본의 웹 17px 본문을 PPT 17pt로 고정하지 않는다.
- 한글 본문: Apple SD Gothic Neo Regular. 제목: AppleSDGothicNeo-SemiBold. 영문 전용 문구: Helvetica Neue. SF Pro를 별도 설치하지 않고 macOS에 설치된 글꼴로 유사한 인상을 만든다.
- 제목은 약한 음수 자간(0 ~ -0.4pt), 본문은 기본 자간. 본문 행간은 대략 1.45–1.5배를 기준으로 읽기 쉽게 조정한다.
- 바깥 여백은 약 0.72인치 이상. 이미지와 본문 사이에 충분한 공간을 두고 정렬 축을 맞춘다. 사진이 필요하면 실제 자료를 사용하며, 없으면 편집 가능한 도형 시안임을 밝힌다.
- 카드·문자·버튼에 그림자를 넣지 않는다. 장식용 그라데이션, 반복되는 테두리, 과도한 아이콘은 피한다. 제품 이미지의 바닥 그림자만 필요에 따라 허용한다.
- 전체 배경은 직각으로 끝낸다. 카드는 필요한 경우만 부드럽게 라운드 처리하며, 캡슐은 행동 요소에 한정한다.
- 텍스트와 도식은 편집 가능한 PPT 개체로 만든다. 샘플을 이미지 한 장으로 굳히지 않는다.

## 폰트와 검수
PPTX는 CSS 폰트 스택이나 macOS 시스템 글꼴 자동 해석을 지원하지 않으므로 실제 설치된 글꼴 이름을 명시한다. 글꼴을 임베드하지 않으므로 다른 운영체제에서는 대체될 수 있다. 실제 PowerPoint 열기·렌더링 여부와 AppKit 미리보기를 구분해 기록한다.

## 샘플
`npm run build`, `npm run inspect`, `npm run preview`로 6장짜리 `output/apple_design_sample.pptx`를 생성·검수한다. 샘플 주제 Focus는 가상의 집중 작업 앱이며, UI와 문구는 디자인 확인용 예시다. 기존 시상식 소스와 데이터는 보존되며 `npm run build:awards`로 기존 발표를 생성할 수 있다.
