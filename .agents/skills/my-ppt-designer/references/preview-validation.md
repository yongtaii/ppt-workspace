# 범용 PPTX 검수 도구

아래 경로는 Skill 디렉터리 기준이다. 파일 경로 인자는 실행한 터미널의 현재 디렉터리를 기준으로 해석한다. 출력 경로를 생략하면 PPTX 옆에 `<파일명>-preview/`를 만든다.

```sh
python3 scripts/inspect_pptx.py /path/to/deck.pptx --out-dir /path/to/preview
python3 scripts/preview_pptx.py /path/to/deck.pptx --out-dir /path/to/preview
```

검수 대상의 슬라이드 수를 알고 있을 때만 `--expected-slides N`을 추가한다. 도구는 발표 파일명, 프로젝트 루트, 색상, 화면 비율, 슬라이드 수를 고정하지 않는다.

## 지원과 한계

- 구조 검수는 Python 표준 라이브러리만 사용한다. ZIP CRC, XML 파싱, 슬라이드 순서, 크기, 텍스트 상자의 겹침과 경계 이탈을 확인한다.
- AppKit 렌더링은 macOS와 Swift가 필요하다. 기본 사각형·타원·다이아몬드·선, 명시적 텍스트 스타일, 내장 이미지, 단색 배경을 대상으로 한다.
- 차트, 표, 그룹, 마스터 객체, 복잡한 도형, 그라데이션, 상속 스타일, 애니메이션, 회전과 일부 글꼴 효과는 완전히 재현하지 못한다. 보고서의 `previewLimitations`와 실제 슬라이드의 요소를 함께 확인한다.
- 테마 색상은 기본 테마를 기준으로 해석한다. 여러 테마를 섞거나 명시적 스타일이 없는 슬라이드는 실제 프로그램으로 확인한다.
- 텍스트 겹침은 상자 경계 기준이므로 의도한 중첩도 경고할 수 있다. 정렬 품질과 이미지 내용은 육안으로 확인한다.
- 무결성 검사 통과는 PowerPoint에서 정상적으로 열었다는 의미가 아니다. 실제 PowerPoint/LibreOffice 검수가 없으면 그 사실을 명시한다.

## 결과

- `slide-NN.png`: 모든 슬라이드의 미리보기. 해상도는 슬라이드 포인트 크기의 2배
- `overview.png`: 슬라이드 수와 화면 비율에 맞춰 자동 구성한 전체 미리보기
- `structural_report.json`: ZIP/XML 및 레이아웃 검사, 미리보기 한계
- `render_report.json`: 렌더링한 슬라이드 수, 텍스트 높이 초과, 글꼴 대체, 미리보기 한계
- `render_model.json`: PPTX에서 읽은 중간 모델. 사진이 있으면 이미지 파일도 추출

구조 오류, 텍스트 높이 초과 또는 글꼴 대체가 있으면 명령은 실패 상태로 종료한다. 미지원 요소는 보고서에 기록하므로 별도로 검토한다. 서로 다른 PPTX의 미리보기는 별도 폴더에 저장해 이전 이미지와 섞이지 않게 한다.
